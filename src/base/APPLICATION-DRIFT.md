# 应用感信号

何时读：设计自查或贴合检查，且该范围的核心活动可能被常规事务式组织打断。对照当前做法档、方向样张和实际成果。以下形式有时很适合当前活动，先判断它怎样影响活动。

| 线索 | 检查时看什么 |
| --- | --- |
| 按钮排 | 操作离开对象后，对象、选择和结果是否仍能对应 |
| 卡片列表 | 局势或空间关系是否被拆开，是否还看得出活动主次 |
| 表格或表单 | 填写是否挤压了活动；用户此刻有没有核对、比较或提交的真实需要 |
| 顶部导航或侧栏 | 切换分区是否打断动作与结果，返回能否恢复 |
| 弹窗叠加 | 是否连续打断，当前状态和返回位置是否仍可辨 |
| 默认组件外观 | 控件的尺度、层次或状态是否盖过已确认的场景特征 |
| 大段说明文字 | 此刻所需动作与后果是否能就在活动中看懂 |

有偏离时记实际位置（场景、状态及可指认元素）、动作或理解受到的妨碍、可恢复该体验的改法。服务当前活动时可保留，并记录理由。成果、截图、样句和契约的绑定见 [做法档](PRACTICE-PROFILES.md)。

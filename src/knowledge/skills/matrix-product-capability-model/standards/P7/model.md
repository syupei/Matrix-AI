## 感知体验设计能力模型

所属模型：《产品领域专家能力要求模型》对应一级能力： P7 感知体验设计依据版本： 总纲 V0.2模块版本： V1.0文档属性： 一级能力主文档 / 唯一正式定义来源状态： 已冻结（2026-08-25）

### 1. 能力定位

### 1.1 唯一正式定义

感知体验设计，是产品经理理解视觉、听觉、触觉和动态等感知因素如何影响用户的注意、辨认、理解、情绪、判断、选择与行为，并据此定义感知目标和原则性要求、识别问题、判断取舍、验收专业设计结果，使产品事实、层级、重点、风险、状态、结果与整体品质被目标用户可靠且适度感知的能力。

本能力不要求产品经理替代视觉设计师、动效设计师、声音设计师、无障碍专家、工业设计师或 AI Design完成专业制作。产品经理的主责是回答：必须让谁在什么情境下感知什么，优先感知什么，希望形成何种效果，哪些误判或排除不可接受，以及最终方案是否真实服务产品目标和用户目标。

本节是“感知体验设计是什么”的唯一正式定义。二级能力.md  只展开七项组成能力，二级能力详细阐述.md只提供学习背景与判断依据，案例回验测试.md  只验证模型解释力，均不另立一级能力定义。

### 1.2 三层价值递进

可用：看得清、听得到、辨得出，知道重点、风险、状态和结果

↓

好用：通过清楚的层级、秩序和多感官协同降低理解与决策成本

↓

喜欢 / 爱不释手：通过稳定、克制、精细且符合定位的整体品质形成强烈偏好

三层不是互相替代的风格等级。高品质必须建立在可用和好用之上；任何以精致、沉浸、极简或品牌感为理由损害可读、可辨、知情判断和用户控制的方案，都不能被评价为优秀感知体验。

代表性用户、设备、设置与环境验收

这是一条判断依赖链，不是固定制作流程。七项能力会在设计任务、方案评审、原型验证、上线验收和持续迭代中反复校验。原则定义、问题识别、取舍判断和结果验收贯穿全部七项，不另设“验收能力”作为第八项。

### 1.4 分析单元

应用本模型前，应声明具体观察单元：完整产品、跨端任务、单个页面、通知、硬件状态灯、声音与震动组合，还是一次关键状态变化。还应记录目标用户、任务、风险、设备、系统设置、环境与时间条件。脱离情境讨论“这个颜色高级吗”“动画顺不顺”不能构成产品判断。

### 2. 核心问题

感知体验设计持续回答以下问题：

1. 哪类用户在什么任务、环境、设备和心理状态下，必须感知哪些产品事实？

2. 用户第一眼、第一耳或第一次触觉反馈应先注意什么，重点强度是否与重要性、风险和最终性相称？

3. 相同含义是否使用稳定线索，不同状态是否足够可区分，跨页面、跨设备和跨通道是否形成秩序？

4. 当前色彩、字体、密度、形态、动效、声音与震动实际会推动何种情绪、信任、风险感、价值判断与选择？这种影响是否真实、适度并尊重用户？

5. 在用户不看屏幕、处于噪声或静音、没有握持设备、设备能力降级时，关键状态与结果仍能否被可靠感知？

6. 不同年龄、感知能力、数字熟练度、系统设置与使用环境下，关键内容是否仍看得清、听得见、辨得出且不过度刺激？

7. 所有感知细节是否共同形成与产品价值和定位一致的品质，而不是局部精致、整体嘈杂或模仿某个知名品牌？

8. 验收证据能否证明用户实际发现、区分、判断和行动正确，而不只证明设计符合某个数值规范或评审者个人偏好？

最终检验不是“设计是否漂亮”，而是：目标用户能否在真实情境中准确感知产品事实，形成与事实相称的注意、情绪和判断，并在长期使用中感受到清楚、可靠、协调和有取舍的整体品质。

### 3. 能力边界

### 3.1 不是专业设计制作能力

P7 不要求产品经理掌握配色软件、字体设计、图标绘制、动效曲线制作、声音合成、触觉曲线调试或完整Design System 制作。产品经理可以提出“风险信息不得被促销信息压过”“支付最终成功必须与处理中明显区分”，但不应在没有专业依据时越权指定每个色号、像素、帧或音频参数。

### 3.2 与 P2“认知与心理引导”：心理目标 vs 感知实现

P2 判断用户带着什么心智模型进入、应形成何种理解、信任、风险权重、动机和心理状态；P7 判断用什么视觉、听觉、触觉或动效线索，以何种层级、强度和节奏使该心理目标被实现。

例如，支付前需要保持与金额和不可逆性相称的警觉，由 P2 主责；金额的视觉权重、警示色、确认声音与触觉强度由 P7 主责。感知表现会影响心理，但不能越过 P2 自行证明心理目标正确。若目标本身错误，更精致的呈现只会更有效地把用户引向错误方向。

### 3.3 与 P3“语义与表达”：文字内容 vs 文字外在表现与非文字表达

P3 只讨论文字内容本身：使用什么概念、名称、句式和文案，说清哪些事实。P7 负责：

1. 文字通过字体、字号、字重、颜色、对比、行距、行长、位置、留白和版式如何被看见、阅读和区分；

2. 图标、图形、图片、色彩、形状、动效、声音、语音、触觉、指示灯等非文字表达如何传递重点、状态、风险与品质。

“永久删除，无法恢复”写什么属于 P3；它是否足够醒目、可读并配合恰当警示图标属于 P7。文字正确不代表用户一定看见；图标和颜色清楚也不能替代必须准确说明的文字。

### 3.4 与 P4“空间与结构”：组织关系 vs 感知强弱

P4 决定信息、对象与功能如何分类、分层、排序、放置、连接和到达；P7 决定既定结构如何通过比例、位置、留白、颜色、字体和其他感知线索表现出层级与重点。

“取消条件应与房价放在同一比较单元”属于 P4；在该单元中总价、取消截止时间和促销标签的感知权重如何安排属于 P7。

### 3.5 与 P5“交互与反馈”：行为闭环 vs 反馈感官形式

P5 负责用户如何发起行为、系统何时响应、能否取消、撤销、修正和重试；P7 负责回应通过哪些感官通道、采用何种形态、强度与节奏被察觉。

点击提交后立即防止重复提交属于 P5；按钮形态变化、处理中动效、声音与震动是否清楚且不过度属于P7。

### 3.6 与 P6“过程与状态”：时间过程 vs 过程如何被感知

P6 定义用户如何经历阶段、等待、中断、恢复和结果；P7 决定阶段、进度、变化和结果如何在视觉、听觉、触觉与动效中被察觉、区分和持续感知。

航班何时被判定延误、何时更新登机口属于 P6；登机口变化在 App、推送、现场屏幕、广播与震动中的显著程度和跨通道一致性属于 P7。

### 3.7 与品牌、营销和专业专项

P7 可以使产品气质与品牌定位一致，但不承担广告创意、品牌传播或营销视觉转化。促销标签是否醒目是P7 判断对象之一，但转化率不能单独证明其感知设计优秀。无障碍标准、医疗警报、航空安全和工业人因等专业领域仍需专项专家参与；P7 负责产品经理必须提出的感知底线、协作要求和结果验收，不替代专项责任。

### 3.8 不讨论技术显示与性能实现

色彩管理、渲染管线、屏幕亮度能力、音频编码、马达控制和动画性能优化属于技术实现。若设备客观限制导致某通道不可用，如何选择替代通道、控制误判并保持体验成立，属于 P7 产品判断。

### 4. 必要专业术语与产品影响

产品经理不需要成为专业制作人员，但应能使用必要术语准确描述问题、理解专业方案并提出可验收要求。

| 术语 | 产品判断所需理解 | 常见影响与验收提醒 |
| --- | --- | --- |
| 色相（Hue） | 区分红、黄、蓝等颜色类别 | 可帮助区分状态、建立品牌联想；含义受文化、行业和上下文影响，不能把“红色必然焦虑”等经验当成普遍规律 |
| 明度 / 亮度感 | 颜色看起来更亮或更暗 | 影响层级、可读性、轻重感和环境适配；浅色不等于次要，深色不天然更可信 |
| 饱和度 | 颜色鲜艳或灰钝的程度 | 高饱和更易抢注意，也更易疲劳和显得促销化；低饱和可能克制，但可能造成低对比与不可见 |
| 色号 | 对某个具体颜色的标识或规格 | 便于一致实现，本身不自动产生固定心理效果；验收应回到背景、面积、材质、亮暗模式和相邻颜色 |
| 对比度 | 前景与背景、相邻元素之间的感知差异 | 决定可读、可辨和层级；关键内容不能只在默认亮度、浅色模式或年轻视力下成立 |
| 字体 | 字形体系与整体文字气质 | 影响辨认、阅读节奏、专业感和产品气质；品牌字体不得牺牲正文可读性和多语言支持 |
| 字号、字重 | 文字尺寸与笔画粗细 | 共同影响可读、层级与注意；更大或更粗不等于更重要，需与信息优先级和系统大字号适配共同判断 |
| 行距、行长、字距 | 连续文字的空间节奏 | 影响扫读、回行、疲劳和信息密度；规则说明不能因极窄行距或过长行宽而实际不可读 |
| 比例、留白、密度、对齐 | 元素之间的大小、间隔、数量和秩序关系 | 影响扫描顺序、分组、稳定感和品质；留白不是越多越高级，密度也不是越低越易用 |
| 图标、形状、图形 | 非文字的辨认与意义载体 | 可加快辨认并提供颜色以外的区分；陌生图标、相似轮廓和无标签符号会增加猜测 |
| 动效时长、速度、缓动、方向、节奏 | 变化发生多快、如何加减速、朝何方向以及如何连续组织 | 可解释因果、方向和状态，也会制造等待感、紧迫感、眩晕或虚假完成感；关键含义不能只靠运动表达 |
| 声音的响度、音高、音色、节奏与重复 | 声音多强、多高、质地如何、何时出现及出现几次 | 影响紧迫、成功、危险、打扰和隐私；高响度不等于高可靠，声音必须考虑静音、噪声和共享空间 |
| 触觉的强度、时长、频率与模式 | 震动多强、多久、几次及其组合规律 | 可在不看屏幕时确认动作或区分事件；相似模式难以学习，过强过频会疲劳，未握持设备时必须有替代 |

这些术语用于提高判断精度，不用于从单个变量直接推导心理结论。感知效果来自变量组合、内容、面积、时序、设备、文化、用户状态和任务风险的共同作用，必须通过代表性情境验证。

### 5. 核心工作内容

1. 建立事实与心理目标基线： 先确认对象、状态、风险、最终性和 P2 所定义的注意、理解、信任与心理目标。

2. 定义感知目标： 明确用户、情境、第一注意点、必要区分、底线、反原则、探索空间和失败条件。

3. 提出原则性要求： 围绕层级、强度、秩序、通道、适配和整体气质提出效果要求，不越权替代专业实现。

4. 评审感知层级： 检查首要、次要、风险、变化、状态和结果的感知权重是否忠实于产品事实。

5. 检查系统秩序： 检查同义线索、状态区分、跨页面、跨设备、跨通道和长期演进的一致性。

6. 校准心理影响： 判断方案实际推动的情绪、信任、紧迫、价值感和选择，识别过度刺激、虚假安心与显著性操纵。

7. 设计多感官要求： 明确各通道分工、冗余、替代、时序、用户控制、隐私和降级方式。

8. 保障包容可用： 在大字号、深浅色、增加对比、减少动态、静音、强光、噪声、移动和能力受限条件下进行压力检查。

9. 定义产品感知品味： 以产品价值和定位为依据，明确整体气质及一致、克制、比例、节奏和细节要求。

10. 执行结果验收： 组合专家走查、代表性任务、多状态、多设置、多环境和用户感受证据，判断是否达到目标。

### 6. 产品感知品味

### 6.1 正式定义

产品感知品味，是用户基于产品在视觉、听觉、触觉、动态节奏及其长期一致性上的综合表现，对产品的品质、克制程度、价值取向、可信度与整体气质形成的判断。

它不是“我觉得好看”的个人偏好，也不是某种固定极简风格。产品感知品味必须能够追溯到具体定位、用户与场景，并从以下六个维度接受讨论和验收。

| 维度 | 主要判断 |
| --- | --- |
| 一致 | 同一含义、气质和品质是否跨页面、状态、设备与版本稳定，产品是否像同一个产品 |
| 克制 | 是否只强调真正重要的内容，懂得什么不该抢注意；是否避免过多颜色、动效、声音、震动和装饰 |
| 比例 | 主次、风险与收益、内容与装饰、局部与整体的感知强弱是否恰当 |
| 节奏 | 浏览、变化、等待、声音、触觉和任务推进是否自然、有序且符合场景速度 |
| 细节 | 对齐、边距、图标、文字、状态、异常与降级场景是否保持稳定品质 |
| 与产品定位一致 | 产品呈现的气质是否真实服务其价值、用户和场景，而非模仿知名品牌或追逐短期潮流 |

### 6.2 品味的底线

品味不能凌驾于可用性、真实性、知情判断与包容性。银行产品可以稳重但不能用低对比小字制造“高级”；儿童产品可以活泼但不能持续高刺激；航空异常提示可以强烈但不能让所有通知都像最后召集；AI 产品可以流畅精致但不能借完成动画制造“答案已核验”的错觉。

### 7. 优秀能力表现

具备优秀感知体验设计能力的产品专业人员通常能够：

1. 先定义用户、任务、事实、风险和效果，再讨论视觉风格或实现方案；

2. 把“更高级、更有冲击力、更有仪式感”等模糊期待转化为可解释、可探索、可验收的要求；

3. 识别信息存在但没有被用户注意、状态不同却看起来相同、事实尚未成立却产生成功感等问题；

4. 理解色相、明度、饱和度、对比、字体、动效、声音和触觉的主要影响，又不把经验关联写成绝对心理公式；

5. 在层级和商业推动之间保留总价、风险、限制与退出方式的知情权重；

6. 让同义线索稳定、异义线索可分，并识别跨端、跨状态和长期迭代中的感知债务；

7. 根据用户是否看屏幕、能否听见、是否握持设备和环境限制设计通道分工与安全降级；

8. 把中年、中老年、低视力、听觉受限、低数字熟练度以及强光、噪声和移动情境纳入默认验收，而不是只做事后补丁；

9. 讨论产品品味时能够指出一致、克制、比例、节奏、细节和定位依据，不以个人审美或品牌模仿作结论；

10. 接受专业设计师和 AI Design 的探索空间，同时能以用户结果证据作出明确验收判断。

### 8. 常见问题与反面案例

### 8.1 用个人偏好替代感知目标

评审只说“红色太俗”“动画不高级”，没有说明目标用户、任务、风险和希望形成的注意或心理效果，团队只能围绕审美权力争论。

### 8.2 用显著性掩盖重要性

酒店列表中折扣、稀缺和会员标签持续高饱和闪现，总价、税费和取消条件却采用小字低对比。用户被推动行动，却没有先获得知情判断所需事实。

### 8.3 所有信息同样突出

银行转账页的收款人、金额、手续费、营销权益和帮助入口使用同等视觉权重，用户必须逐项阅读，无法快速确认高风险事实。

### 8.4 把颜色当作唯一状态

成功与失败只以绿点和红点区分；色觉差异、灰度屏、强光或低质量显示下，状态失去可辨性。

### 8.5 多感官反馈与事实不同步

指令提交后立即播放成功声音和强触觉，但资金仍在处理中。感知仪式感越强，用户越容易误判结果已经最终成立。

### 8.6 把系统设置适配当作附加功能

默认字号下页面精致，大字号时金额截断、按钮被遮挡；减少动态后关键状态不再出现。产品只对默认设备上的年轻用户可用。

### 8.7 局部精致掩盖系统粗糙

首页和发布会演示经过精细打磨，空白、等待、失败、离线和旧设备状态却样式混乱、反馈缺失。品味没有形成系统品质。

### 8.8 用“极简”删除必要线索

智能门锁只保留一枚极简状态灯，却让连接中、已上锁、低电量和离线共享相似颜色与闪烁方式。外观克制转化为安全误判。

### 9. 七项二级能力概览

| 序号 | 二级能力 | 主要回答 | 核心产出判断 |
| --- | --- | --- | --- |
| 1 | 感知目标定义能力 | 谁在何种情境下必须感知什么并形成何种效果 | 感知目标、底线、反原则、探索空间与验收条件 |
| 2 | 感知层级与重点判断能力 | 用户应先注意什么，各事实应多强 | 注意顺序、主次、风险、状态与结果的显著性判断 |
| 3 | 感知一致性与秩序判断能力 | 同义线索是否稳定、异义线索是否可分、整体是否有序 | 跨页面、跨端、跨通道与跨版本的感知规则 |
| 4 | 感知心理影响判断能力 | 当前表现实际推动什么情绪、信任、价值与选择 | 心理影响、事实相称性、适度性与自主判断边界 |
| 5 | 多感官反馈判断能力 | 视觉、声音、触觉和动效如何分工、替代与降级 | 通道组合、时序、强度、用户控制、隐私与替代方案 |
| 6 | 感知可用性与包容性判断能力 | 不同人群、设置、设备与环境下是否仍可感知 | 可读、可辨、非单一通道、系统适配与代表性验证 |
| 7 | 产品品味与品质判断能力 | 感知系统是否形成与定位一致的整体品质和偏好 | 一致、克制、比例、节奏、细节与定位一致性判断 |

七项能力的完整定义、问题、关注重点、案例、验收证据和内部边界，统一见 二级能力.md 。

### 10. 验收原则与证据

### 10.1 原则性要求的推荐结构

一项可执行的感知要求至少包含：

1. 对象： 哪类用户；

2. 情境： 什么任务、设备、环境、设置与心理状态；

3. 事实： 必须感知什么重点、风险、状态、变化或结果；

4. 目标： 希望形成何种注意顺序、理解、情绪、判断和行为；

5. 底线： 哪些误判、漏判、刺激、排除或品质问题不可接受；

6. 原则： 对层级、强度、通道、秩序、适配和气质提出什么要求；

---

<a id="pdf-page-233"></a>

<!-- 原 PDF 第 233 页 -->

7. 验证： 用哪些代表性任务、用户、设备、设置和环境验收。

例如，不应只要求“让支付成功更有仪式感”，而应要求：成功感只能在交易结果最终成立后出现；“已接收”“处理中”和“成功”必须可区分；静音或未握持设备时仍有替代；反馈强度应与金融风险和可信定位一致。

### 10.2 验收不等于数值合规

字号、对比度、时长、音量和触控尺寸等标准可作为底线依据，但不能替代产品验收。正式验收应组合：

专家走查： 检查层级、含义、强度、通道、适配、心理影响和整体品质；

代表性任务： 观察用户能否发现、辨认、区分并正确行动；

多环境压力测试： 强光、噪声、移动、静音、离屏和设备降级；

多设置压力测试： 大字号、深浅色、增加对比、减少动态、通知关闭；

多状态检查： 正常、等待、成功、失败、异常、风险和结果不确定；

主观感受证据： 用户对清楚、舒适、可信、克制、品质和气质的描述及原因。

证据重点包括发现时间、第一注意点、扫描顺序、误判与漏判、状态区分、任务完成、打扰与疲劳、心理感受、跨端一致性和品质判断。当前阶段不建立统一分数、权重或职级标准。

### 11. 与其他一级能力的关系

感知体验设计是产品事实进入用户感官并进一步影响认知和心理的实现层。它以产品逻辑为事实基线，以认知与心理引导为目标依据，与语义、结构、交互和过程共同形成完整体验。

| 一级能力 | 与 P7 的协作关系 | 主要边界 |
| --- | --- | --- |
| P1 产品逻辑 | 提供对象、关系、规则、状态和结果的事实基线 | P1 定义事实是什么；P7 决定事实如何被可靠感知 |
| P2 认知与心理引导 | 定义用户应形成的理解、信任、风险权重和心理状态 | P2 定义心理目标；P7 选择感知通道、层级、强度和节奏实现 |
| P3 语义与表达 | 提供具体文字内容和概念体系 | P3 讨论文字说什么；P7 讨论文字如何呈现及所有非文字表达 |
| P4 空间与结构 | 提供信息、对象、功能和入口的组织关系 | P4 决定如何组织与到达；P7 决定结构如何呈现为可感知层级 |
| P5 交互与反馈 | 提供意图表达、响应、确认、撤销和修正机制 | P5 定义反馈闭环；P7 定义反馈采用何种感官形式 |
| P6 过程与状态 | 提供阶段、等待、中断、恢复和连续体验 | P6 定义变化如何被经历；P7 定义变化如何被察觉和区分 |

### 12. V1.0 冻结结论

本模块已完成九类代表性观察单元的案例回验，覆盖 Apple 系统适配与 Apple Pay、Booking / Agoda、银行转账、航空登机口变化、Google Nest 智能家居、Microsoft Teams、公共服务终端以及中年、中老年和普通商务用户。回验同时包含 good、bad 和 mixed 证据，没有把知名品牌或市场成功作为质量结论。

回验确认：

七项二级能力均在多个案例中形成独立证据；

“层级与重点 / 心理影响”“一致性与秩序 / 品味与品质”“多感官反馈 / 包容性”三组敏感边界可以稳定分责；

P7 与 P2 可按“心理目标 / 感知实现”分责，与 P3 可按“文字内容 / 文字外在表现和非文字表达”分责；

模型能够识别问题、解释影响并提出原则性改进要求，没有退化为设计师教程、风格评论或工具技能；

产品感知品味可通过一致、克制、比例、节奏、细节和定位一致性形成可讨论证据，没有退化为个人审美；

未发现需要新增、删除、合并或改名二级能力的阻断性问题。

冻结后继续保留四项应用约束：

1. 任何感知判断必须先确认产品事实和 P2 心理目标；

2. 专业术语用于精确描述和验收，不得被写成单变量心理公式；

3. 包容性应进入默认设计和代表性验证，不只依赖独立“老年模式”或事后补丁；

4. 品味判断必须以产品定位和跨状态整体证据为依据，可用与好用是其前置条件。

据此，07_感知体验设计 自 2026-08-25 起正式冻结为 V1.0。冻结范围包括：一级能力定义、七项二级能力名称与顺序、四份正式文档职责、三层价值递进、产品感知品味定义及主要边界。后续可补充兼容性案例、学习材料与标准更新；如出现需要改变上述结构的反证，须重新进入正式评审并记录版本变更。

### 1. 文档职责与统一原则

本文档只展开感知体验设计的七项二级能力，不另行定义一级能力 P7。一级能力的唯一正式定义、总体边界、必要术语和与其他一级能力的关系，统一以 能力模型.md  为准。

七项二级能力按判断依赖排列：

1. 感知目标定义能力

2. 感知层级与重点判断能力

3. 感知一致性与秩序判断能力

4. 感知心理影响判断能力

5. 多感官反馈判断能力

6. 感知可用性与包容性判断能力

7. 产品品味与品质判断能力

该顺序不表示固定设计流程。每项能力都必须从产品经理视角落到四类行为：定义原则、识别问题、判断取舍、验收结果。产品经理不需要提交专业视觉、动效、声音或触觉制作稿，也不能只以“交给设计师 / AI Design”结束产品判断。

# P7-2 感知层级与重点判断能力：详细阐述

> 《产品领域专家能力要求模型》P7 感知体验设计 V1.0 原文，按章节拆分，正文未改写。

## 3. 二级能力二：感知层级与重点判断能力

### 3.1 能力定义

判断页面或产品中的信息、动作和状态是否通过大小、位置、对比、间距、分组、动效、声音和触觉建立了正确的优先级，使用户无需逐项分析即可形成合理的注意顺序。

### 3.2 层级的本质

感知层级不是“标题大、正文小”这么简单。它是在有限注意力下分配信息权重。用户往往先获得整体印象，再识别局部内容。视觉复杂度和原型熟悉度能够在非常短的时间内影响用户的审美与第一印象。[S8]

产品经理需要判断：

当前任务真正最重要的是什么；

哪些内容需要立即出现，哪些可以延后；

哪些要强提醒，哪些应保持安静；

重点之间是否互相竞争；

用户是否因为感知层级错误而做出错误选择。

### 3.3 建立层级的主要感知变量

### 3.3.1 大小

较大的元素通常更容易获得注意，但“大”应表达重要性，而不是仅用于装饰。若营销横幅比订单总价更大，用户可能首先处理非核心信息。

验收问题：

最大的元素是否真的是最重要的？

页面是否有太多同等级大元素？

中老年用户需要更大文字时，层级是否仍成立？

### 3.3.2 位置

页面上方、视线起点、中心区域或拇指易触区域通常更容易获得注意和操作，但具体取决于设备、阅读方向和任务。

验收问题：

核心信息是否必须滚动后才出现？

风险提示是否远离相关动作？

主要动作是否处在自然任务流末端？

### 3.3.3 对比

对比可以来自亮度、颜色、大小、粗细、形状、空间或运动。对比越多不代表越清晰；当所有内容都高对比时，用户反而无法判断重点。

验收问题：

页面是否有唯一或有限的主强调？

次要内容是否被压得几乎不可见？

深色模式下对比关系是否反转或失效？

### 3.3.4 留白和间距

留白不是“空”，而是在表达分组、边界和节奏。相近元素通常被视为一组；过近会误合并，过远会切断关系。

验收问题：

相关信息是否靠近？

不相关模块是否有足够分隔？

留白是否导致页面过长和操作低效？

### 3.3.5 字号与字重

字号、字重和颜色共同构成文字层级。过细字重配合小字号容易在低对比、强光或视力下降情况下失去可读性。Apple 的平台指南也将字体大小和字重视为易读性的共同因素，并鼓励支持动态文字大小。[S4][S5]

验收问题：

是否存在“为了高级而使用过细灰字”的情况？

一级、二级、正文、辅助信息是否具有可辨识但不过多的层级？

放大字体后，层级是否仍然清楚？

### 3.3.6 信息密度

密度不是单纯“内容多”。它由元素数量、差异程度、间距、层级、装饰和交互控件共同决定。

低密度适合：

第一次使用；

高风险决策；

普通消费者；

需要集中注意的单一任务。

高密度可能适合：

熟练商务用户；

数据监控；

高频操作；

需要同时比较大量信息的任务。

产品经理不能把“低密度”等同于高级，也不能把“高密度”等同于专业。关键是用户能否在目标时间内找到信息并保持整体认知。

### 3.3.7 动效、声音与触觉的显著性

运动、突然声音和明显震动会强制争夺注意力，应保留给真正重要或需要即时反应的事件。若普通收藏也使用强烈震动，系统就难以为支付失败、门锁异常等高风险事件保留更强信号。

### 3.4 层级验收的三次观察

第一次：一秒观察

快速查看页面，不阅读文字，回答：

第一眼看到了什么？

觉得当前任务是什么？

感到安全、紧张、嘈杂还是平静？

第二次：任务扫描

给出明确任务，例如“找到是否可以免费取消”，观察用户是否能在短时间内定位。

第三次：完整阅读

检查详细信息是否仍然完整、准确，避免只突出重点而隐藏必要条件。

### 3.5 常见错误

主按钮、优惠、风险、标题全部使用同样强度；

辅助文字对比过低，实际不可读；

过多彩色标签造成“彩色噪声”；

所有模块都用卡片和阴影，无法分辨主次；

为保持页面“干净”而隐藏用户决策所需信息；

商务工具过度低密度，导致熟练用户频繁滚动；

面向中老年用户仍使用小字号、细字重和紧密控件。

### 3.6 案例

酒店预订页

关键层级通常包括：总价、日期、房型、取消政策、早餐和主要操作。若“折扣百分比”和“仅剩数量”比最终总价更抢眼，模型应判定为重点分配失衡，而不是因为产品知名就视为正确。

银行转账页

收款人、金额和确认操作应形成强主线；促销入口和推荐服务应保持安静。若银行品牌插画占据主视觉、收款人信息却以小灰字呈现，属于感知目标与层级双重错误。

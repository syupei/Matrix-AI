# P6 过程与状态：二级能力结构、边界与冻结结论

> 《产品领域专家能力要求模型》P6 过程与状态 V1.0 原文，按章节拆分，正文未改写。

### 9. V1.0 冻结结论

七项二级能力分别承担生命周期骨架、变化理解、等待进度、中断恢复、异步到达、异常降级和跨场景连续的主责问题，合在一起覆盖产品随时间展开的主要过程问题。

十类案例回验确认：七项能力均具有独立判断价值，未发现稳定覆盖空白、同义重复或需要新增能力项的证据；内部敏感边界可按“完整阶段 / 单次变化”“前台等待 / 离场异步”“中断恢复 / 异常策略”“单场景恢复/ 跨场景连续”稳定区分。

与其他一级能力也能稳定按主责分界：P1 定义状态事实与合法转换，P2 定义预期和心理目标，P5 完成一次动作的即时闭环，P7 决定感官呈现；P6 负责这些事实和行为如何在时间中被用户经历。

据此，七项能力的名称、数量、顺序、定义及主要边界自 2026-08-25 起随 06_过程与状态 冻结为V1.0。不得在本文件之外建立平行的二级能力定义；后续兼容性迭代必须保留“产品时间不替代技术性能、过程事实不替代 P1 状态体系、预期管理不脱离真实承诺、连续性不牺牲安全与最新事实”的应用约束。

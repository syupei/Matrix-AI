# 游戏与玩乐做法：文案

何时读：方向样张任务或 CD-1–CD-4，且项目做法档在该活动范围采用游戏文案做法。样句交接和共同贴合记录见 [方向样张](../../../../matrix/orchestration/DIRECTION-SAMPLE.md)。

## 怎样在玩法时刻写

- 跟着一局列时刻：何时轮到我、可做什么、发生了什么、得到或失去了什么、怎样再来一局。每句标键、触发、变量、最大长度、同屏内容与是否可跳过。选调性一致、接近目标长度的句子放回场景，再试最窄视口和最长实际值。
- 先说有意义的结果，再指出需要行动的一步。例如回合结果「掷到 6，再走一格」，其后果是棋子再前进一次。选路时可写「已选捷径，掷骰出发」，后果则是路线已选、棋子仍留在岔路。样句只采用本项目实际规则。不同轮换文案保持同样的规则和结果。语气可随时刻变化：轮到我简短明确，庆祝可用角色口吻，失去资源或退出要明确限额、影响和恢复选择。
- 把新手引导放到第一次真的需要行动的地方。第一次掷骰或选择分岔时提示该对象现场可用的动作，完成后收起。遇到状态变化或回看时提供可发现的规则入口。保留交接和核对记录的工作用语，检查没有混入玩家界面。

## 与事务处理的差异及复查

事务流程里的说明可供阅读和回查，玩法中的短提示要跟得上动作。新手离开对局去读规则才能知道可点何处、每回合固定出现同一句阻挡提示，或几种不同结局共用一句模糊回执时，把文字放回相关时刻和对象，再通读完整一局。语气变化以不损失规则、损失和下一步为边界。

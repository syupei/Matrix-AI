# 游戏与玩乐做法：文案

按调性契约与玩法时刻写产品里的语言。工作状态和核对记录使用清楚、准确的工程语言。

- 方向样张给两种语气，每种覆盖 6–8 句。按核心循环择取动作、事件、获得或失去、超越、落后和终局。合同记录选定语气与实际样句。
- 样句写「骰子停在 6，你再走一格」一类当下反馈；避免「系统已执行随机数解析」。同一时刻的轮换句保持同一结果，记录字符限制与最窄目标视口。
- 玩笑、角色口吻和适度夸张服从调性契约。扣除资源、退出、失败等后果用准确文字，普通提示及错误仍按共同文案质量规则。
- CD-1 按当前已确认的调性契约定判据。交出玩法文案前，让检查者仅看契约、截图及样句，指出语气与品类偏差。保留位置与结论；未通过退给内容修改。

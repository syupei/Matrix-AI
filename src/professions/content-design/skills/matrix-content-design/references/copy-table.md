# 文案表

何时读：建立或更新文案表；产品、设计、研发引用文案时；文案变更时。

文案表是用户看到的文字的唯一来源。设计和研发只引用键，不抄写文字。

| 字段 | 内容 |
| --- | --- |
| 键 | 稳定的编号，例如 `MSG-LOGIN-07`；改文字不改键，含义变了才换新键 |
| 情境 | 对应的产品规则或用户情境的编号与版本 |
| 文字 | 成稿；多语言时同一个键下按语言分列 |
| 变量与长度 | 动态值的名称与格式；位置允许的最大长度 |
| 语气 | 语气要求，例如普通提示、关键后果、错误 |
| 状态 | 候选、已认可；作者自拟只标候选 |
| 使用位置 | 页面、状态或通知的位置 |

- **内部异常不直接成为文字**：研发把内部异常归为产品定义的用户情境，情境对应文案的键。
- **变更**：改了文字，按 C04 §5 通知已在使用的下游；质量工程复核显示效果。
- **缺陷定级**：按 C22，本专业的例子见 L01。

# 游戏与玩乐做法：产品

在方向样张先判断品类，再决定采用的做法档。MODEL 写明 `practice_profile` 及判断依据。品类可以混合，以主要活动选择做法档，局部例外列入契约。简报附 2–3 个同核心机制参照，写明借鉴的布局、操作、反馈或语气，以及是否看过截图或视频。列至少一个要避免的方向。产品合成各专业的引用和版本，出现分歧交回对应专业。

- 用一句话说明循环，再列表说明每次行动的选择、输入、状态变化与反馈。为中断、非法行动、平局及终局写规则或待定项。
- 记录随机来源、可复用的确定性输入、公平边界、回合节奏及预计时长。列胜负、追赶机制及它们影响谁。
- 有争议的胜负、节奏和公平取舍交人确认，产品可提建议。验收项按局内事件及可观察结果组织，可用固定输入测试规则，体验交实际试玩。
- 在 P-1 方向样张里与人一次确认样张和澄清结论，随后写[调性契约](../assets/tone-contract-template.md)。P-2 从该版本继续；改动时记录新版本并通知受影响的设计、内容和质量工程。

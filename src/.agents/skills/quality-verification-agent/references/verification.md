# 检验与测量

何时读：Q2 增量检验；Q3 范围回归与测量。

## 增量检验（Q2）

- 收到增量构建的检验请求（任务卡、可试用版本、对应的验收条目）后，先核对来源摘要（R01）。
- 测试先行的部分（技术方案的测试策略约定的，通常是规则与计算核心）在实现前写好验收测试，交给增量构建运行。
- 实现后自己运行全部相关验收，不采信转述的结果；记录命令、环境、原始输出与证据层级。
- 检查假完成的迹象：桩或写死的返回代替真实路径、跳过或删改的测试、吞掉的错误、只在本地能跑。发现就不判通过，记缺陷（R03）。
- 结果写回任务：PM 统筹时用任务工具记录检验（你是 checker）；否则写进增量记录引用的检验记录。

## 验收测试的维护

- 验收测试由你维护。技术方案在工程基础中加一条自动检查：改动验收测试位置的合入，没有你的检验记录就阻断。仓库或宿主做不到时如实记录，改由交叉审查专门检查这一项。
- 实现者认为验收写错时，向你提请求。你核对产品源：产品没变就维持；产品要改就先回到产品，再改测试。

## 测量（Q3 与需要时）

- 负载、场景与数据固定，写明环境与设备，先预热，重复多次。
- 保留原始样本；报告百分位（如 p95、p99）与最差值，不只报平均。
- 对照质量要求的目标；模拟环境与真机分开写证据层级，到不了的层写明由谁在哪个阶段验证。

## 范围回归（Q3）

- 在主线上对发布范围全量回归，汇总覆盖表、检验结果、测量与未关闭的缺陷。
- 按"证据与边界"逐条提供：证据与层级、能证明什么、不能证明什么、余下由谁在哪个阶段验证，交增量构建放进范围完成评审包。

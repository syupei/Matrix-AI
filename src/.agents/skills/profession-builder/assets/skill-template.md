# 技能入口骨架

何时读：写新专业的技能入口与指引索引时。把花括号换成实际内容；入口不超过 3,500 字，指引索引不超过 1,500 字。链接写成从技能目录出发的相对路径，例如共同底线是 `../../../collaboration/CORE.md`。

## 入口（SKILL.md）

```markdown
---
name: {技能标识}
description: {做什么、用于什么；不用于什么}
---

# {名称}

版本：0.1。角色标识：{专业标识}。

{一段话：负责什么判断，不负责什么。}

## 启动

有项目任职或具体任务包时，先按团队执行（C90）核对身份与范围。

1. 读共同底线、共用规则索引和本技能的指引索引。
2. {续做时从哪些文件恢复。}
```

# 发布工作区模板

建立 `engineering/release/` 下的文件时按需取用；小型档只用最后一节。项目已有的组织方式、ID 和人的修改优先。`{...}` 为填写处，不相关的字段删去；还没形成的成果写"未形成"，不给假链接。

## 00-工作状态.md

```markdown
# 发布与交接工作状态

- 负责人：{人员 id，只有一人时写"用户"} / engineering-build
- 当前位置：{发布与交接：共 3 步，当前进行第 X 步「名称」；当前批次}
- 工作情况：{…}
- 最新已确认成果：{发布决定的版本与范围；没有写无}
- 进行中：{修复、演练或批次}
- 在等谁：{人员与事项，如账号、合规材料、运维负责人、发布决定；没有写无}
- 下一步：{下一动作或停止原因与恢复}

（以上七行是摘要块，供 PM 汇总，见 TEAM §5；以下为详细状态。）

- 输入：{范围完成评审的记录与版本；进入发布准备的决定}
- 只能由人办的事项：{事项、由谁办、状态}
```

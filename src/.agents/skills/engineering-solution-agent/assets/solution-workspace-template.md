# 技术方案工作区模板

建立 `engineering/solution/` 下的文件时按需取用；小型档可以合为一份技术简报。项目已有的组织方式、ID 和人的修改优先。`{...}` 为填写处，不相关的字段删去；还没形成的成果写"未形成"，不给假链接。

## 00-工作状态.md

```markdown
# 技术方案工作状态

- 项目/任务：{标识}
- 角色与规则版本：{engineering-solution，skill 版本}
- 流程位置：{技术方案：共 4 步，当前进行第 X 步「名称」；回查另注}
- 档位与评审模式：{小型/中型……；委托优先或标准模式}
- 输入基线：{E1 交接位置与版本；产品、设计基线}
- 委托边界：{位置、版本、确认依据}
- 工作情况与本轮完成：{…}
- 阻断与回升事项：{…}
- 下一动作或停止原因与恢复：{…}
```

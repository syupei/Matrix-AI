# P7 感知体验设计：二级能力结构、边界与冻结结论

> 《产品领域专家能力要求模型》P7 感知体验设计 V1.0 原文，按章节拆分，正文未改写。

### 9. 二级能力边界与内部一致性检查

### 9.1 七项能力的不可替代主责

| 能力 | 不可替代的主责问题 | 典型判断证据 |
| --- | --- | --- |
| 感知目标定义 | 感知设计究竟要让谁在何种情境下感知什么、形成何种效果 | 目标、底线、反原则、探索边界、验收条件 |
| 感知层级与重点 | 各事实在感知上谁先谁后、应该多强 | 第一注意点、扫描顺序、显著性、风险与结果权重 |
| 感知一致性与秩序 | 同义是否稳定、异义是否可分、跨场景是否有共同感知语法 | 状态辨认、跨端迁移、线索冲突、感知债务 |
| 感知心理影响 | 具体表现实际推动什么情绪、信任、风险感和选择 | 事实相称性、紧迫与安心、操纵风险、长期刺激 |
| 多感官反馈 | 各感官通道如何分工、同步、冗余、替代和降级 | 离屏、静音、噪声、未握持和隐私情境表现 |
| 感知可用性与包容性 | 不同用户、设置、设备和环境下是否仍看得清、听见、辨得出 | 大字号、对比、非单通道、减少动态、代表性任务 |
| 产品品味与品质 | 感知系统是否形成与定位一致的整体品质和长期偏好 | 一致、克制、比例、节奏、细节与定位证据 |

### 9.2 高频内部边界

| 易混淆边界 | 主责区分 | 检查结论 |
| --- | --- | --- |
| 感知目标定义 vs 层级与重点 | 前者决定什么结果必须实现；后者判断各内容实际以什么强弱进入注意 | 目标是上游依据，层级是核心实现判断；不重复 |
| 层级与重点 vs 心理影响 | 前者回答用户先感知什么、强度是否匹配；后者回答该强度进一步造成何种情绪、信任和选择 | Booking 稀缺提示既可检查注意权重，也可检查紧迫推动；可按主要问题分责 |
| 一致性与秩序 vs 品味与品质 | 前者判断感知语法稳定和可预测；后者综合一致、克制、比例、节奏、细节和定位形成整体品质 | 一致是品味的必要维度但非充分条件；不合并 |
| 多感官反馈 vs 可用性与包容性 | 前者设计通道分工、同步与降级；后者验证不同用户和环境中结果是否可感知 | 航空跨通道分工与听觉受限用户的结果验证可稳定分责 |
| 心理影响 vs 品味与品质 | 前者检查某表现对当下情绪、信任和选择的影响；后者检查跨状态、长期整体品质与偏好 | 即时影响与系统综合判断不同；不重复 |
| 层级与重点 vs 可用性与包容性 | 前者处理相对强弱与注意顺序；后者保障最低可读、可辨和适配 | 内容可读后仍可能层级错误；层级正确也可能对某类用户不可读 |

### 9.3 与相邻一级能力的边界检查

| 相邻能力 | 对方主责 | P7 主责 | 判定规则 |
| --- | --- | --- | --- |
| P1 产品逻辑 | 定义对象、规则、状态和结果事实 | 让既定事实可靠可感知 | 若事实尚不清，先归 P1；事实清楚但用户感知错误，归 P7 |
| P2 认知与心理引导 | 定义用户应形成何种理解、信任、风险权重和心理状态 | 用感知线索、强度和节奏实现并验收 | “需要什么心理状态”归 P2；“当前表现造成什么影响”归P7 |
| P3 语义与表达 | 文字内容说什么、如何措辞 | 文字外在呈现与全部非文字表达 | 改词句归 P3；改字体、颜色、图形、声音、触觉或动效归 P7 |
| P4 空间与结构 | 分类、分层、排序、放置、连接和到达 | 既定结构如何呈现为感知层级 | 信息放在哪里归 P4；放置后是否被感知为重点归 P7 |
| P5 交互与反馈 | 行为如何发起、响应、撤销和修正 | 反馈通过何种感官形式呈现 | 是否反馈归 P5；反馈如何被看见、听见或感到归 P7 |
| P6 过程与状态 | 阶段、等待、中断、恢复和连续体验 | 阶段变化如何被察觉与区分 | 状态何时变化归 P6；变化显著性与通道归 P7 |

### 9.4 遗漏与合并检查

本轮检查未发现需要新增“视觉设计”“声音设计”“动效设计”“触觉设计”或“验收能力”：

按专业媒介拆分会把模型写成设计岗位能力，并造成同一产品判断在多个媒介中重复；

各媒介已由层级、秩序、心理影响、多感官、包容性和品质六类横向判断覆盖；

原则定义、问题识别、判断取舍和验收结果是七项能力的共同工作方式，不应成为独立能力；

“品牌感”已由产品品味与定位一致性覆盖，不需要新增品牌视觉能力；

“可访问性”与产品经理需要承担的包容结果已由第六项覆盖，专项标准和技术实现不进入能力树；

色彩、字体、版式、图形、图片、动效、声音和触觉均属于感知对象，不构成遗漏。

### 9.5 逻辑一致性检查

七项能力满足以下共同约束：

1. 都从产品事实、用户目标、产品目标和具体情境出发；

2. 都以产品经理的原则定义、问题识别、判断与验收为行为证据；

3. 都允许专业设计人员和 AI Design 保持实现探索空间；

4. 都以用户实际感知和任务结果为主要证据，不以风格、工具或单项数值替代；

5. 都受真实性、知情判断、用户控制和包容性约束；

6. 都可以跨视觉、听觉、触觉和动效媒介应用；

7. 都能在可用、好用、喜欢 / 爱不释手三层中找到作用位置。

检查未发现定义循环、上下位混乱、同义重复或稳定遗漏。

### 10. V1.0 结构验证与冻结结论

九类案例回验为七项能力提供了跨产品、跨人群和跨环境的独立证据。内部边界与 P1–P6 相邻边界均可按主责问题稳定判断，未出现必须改变一级定义、增加或删除二级能力的重大问题。

冻结后继续保留以下应用约束：

不能从颜色、字体或动效单变量直接推导心理结论；

多感官并非通道越多越好，应按事实重要性、情境可用性、打扰和隐私取舍；

包容性是默认底线，但不要求每个产品采用完全相同的专项模式；

品味必须建立在可用、好用和真实产品定位之上；

七项能力用于完整检查，不要求每个观察单元都同等强度介入。

据此，七项二级能力名称、顺序、基本定义与主要边界自 2026-08-25 起作为 V1.0 正式冻结。后续可在不改变结构与主责边界的前提下补充案例、判断依据和兼容性说明；结构性调整须重新进入正式评审并记录版本变更。

# P7-5 多感官反馈判断能力

> 《产品领域专家能力要求模型》P7 感知体验设计 V1.0 原文，按章节拆分，正文未改写。

### 6. 多感官反馈判断能力

能力定义

判断视觉、动效、声音、语音、触觉、指示灯等感知通道在具体情境中应如何分工、组合、冗余、替代与降级，使用户可靠感知操作被接收、系统正在处理、状态发生变化、结果成立或风险出现，同时避免通道冲突、无效重复、打扰和隐私暴露。

核心问题

当前情境中用户能看到、听到、感到哪些通道？哪些通道可能失效？

什么事实需要单通道，什么高风险或高紧迫事实需要冗余？

各通道是否表达同一事实，并在出现时点和最终性上同步？

声音、触觉、灯光与动效的强度、频率和重复是否与重要性相称？

静音、噪声、离屏、未握持、共享环境或设备不支持时如何安全降级？

用户能否控制、减少或关闭非关键刺激，而不因此错过安全信息？

声音、语音和通知预览是否泄露隐私或打扰他人？

关注重点

通道可用性与任务情境，不默认用户持续看屏幕；

高风险事实的冗余和替代通道；

视觉、声音、触觉、硬件灯和系统通知的含义与时序一致；

日常、重要、紧急与安全事件的强度分级；

静音、通知关闭、设备不支持、离屏和远程使用的降级；

用户控制、个性化与打扰预算；

公共空间、家庭共享、会议和夜间场景中的隐私与社会影响。

原则性产出与验收证据

原则性产出： 通道分工图、关键事件冗余原则、强度分级、时序要求、控制与隐私规则、降级和替代方案。

验收证据： 不看屏幕、静音、噪声、未握持和设备降级时的事件发现率；跨通道状态误判；重复刺激与关闭率；隐私暴露；用户能否仅凭所处通道正确区分事件等级。

为什么重要

用户并不总在看屏幕，也不总能听见声音或感到震动。单一通道会在真实环境或能力受限时失效；多通道使用不当又会放大误判、打扰与隐私风险。本能力确保反馈既可靠又适度。

常见错误

将声音或颜色作为关键结果的唯一通道；

不论事件重要性都使用相同声音和震动；

视觉显示处理中，声音和触觉却表达成功；

为了“有反馈”给每个轻微动作增加触觉和声音；

忽略静音、未握持、强光、噪声和远程控制；

通知在共享屏幕或公共空间暴露敏感内容；

允许关闭全部反馈，却没有安全事件的替代策略。

简洁案例

航空登机口变化不能只依赖 App 红点，也不应让每条旅行提醒都触发同等级广播与强震。原则应按普通更新、临近登机、登机口变化和最后召集分级，并保证现场屏幕、App、推送、声音与触觉表达同一航班事实；静音时仍须有可回查的视觉记录。

与相邻能力边界

P5 定义系统应在何时反馈、用户能否撤销和重试；P6 定义变化如何随时间发生；本能力决定反馈和变化使用哪些感官通道以及如何组合。“感知可用性与包容性”检查不同人群和能力条件下是否可感知；本能力主责通道系统本身的分工、同步和降级。

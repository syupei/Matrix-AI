# P2 认知与心理引导：二级能力结构、边界与冻结结论

> 《产品领域专家能力要求模型》P2 认知与心理引导 V1.0 原文，按章节拆分，正文未改写。

### 8. V1.0 冻结结论

六项二级能力分别承担当前理解、认知投入、行动条件、结果预期、认知与行为变化、情境心理状态的主责问题，合在一起覆盖用户理解、判断、预期、行动与稳定使用的主要心理过程。

六类案例回验确认：六项能力均具有独立判断价值，未发现覆盖空白、同义重复或需要新增能力项的证据；

内部敏感边界可按“当前理解 / 认知改变”“认知投入 / 行动意愿”“结果预期 / 心理状态”稳定区分，与其他一级能力也能按“心理目标与判断 / 具体表现与机制”分责。

据此，六项能力的名称、数量、顺序、定义及主要边界自 2026-08-24 起随 02_认知与心理引导 冻结为V1.0。不得在本文件之外建立平行的二级能力定义；后续兼容性迭代必须保留“习惯形成具有条件性、心理状态调节回到具体事实与情境、引导尊重用户自主”的应用约束。

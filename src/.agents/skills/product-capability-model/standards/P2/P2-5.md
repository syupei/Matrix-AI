# P2-5 用户认知迁移与习惯形成能力

> 《产品领域专家能力要求模型》P2 认知与心理引导 V1.0 原文，按章节拆分，正文未改写。

### 6. 用户认知迁移与习惯形成能力

能力定义

判断用户如何借助现实经验、其他产品经验和本产品中的既有规律理解新对象与行为，并通过情境化实践、一致反馈和支持渐退，持续更新心智模型，从首次成功走向自主、熟练和稳定使用；当长期重复确实为用户创造价值时，帮助其形成健康、可控且可修正的使用习惯。

“习惯形成”不是提高使用频率，也不是所有产品的普遍目标。一次性、低频或高风险任务可能只需要可迁移的理解和在必要时正确行动；只有稳定重复本身对用户有持续价值时，习惯才是合理结果。

核心问题

哪些已有经验可以帮助用户理解新能力，哪些旧经验会造成负迁移？

用户如何从第一次接触走向第一次成功，而不被集中教学压垮？

一次成功能否形成可迁移规律，使用户在相似场景中自主行动？

产品何时应提供情境提示，何时应逐步减少支持并让用户获得熟练度？

熟练用户如何提高效率，同时不破坏新手可理解性？

产品规则改变后，用户如何修正旧习惯和旧预期？

长期重复是否真的符合用户目标，习惯是否允许暂停、改变和退出？

关注重点

现实经验、通用产品经验和产品内部规律的迁移；

正迁移、负迁移与旧习惯冲突；

首次成功、情境化学习和通过实际任务理解；

提示、示范、实践、反馈与支持渐退；

新手到熟练用户的效率路径；

跨功能、跨设备和相似场景的一致规律；

规则变化后的再学习和旧习惯校准；

长期重复对用户的真实价值、可控性和可停止性。

为什么重要

复杂产品不可能在首次使用时一次讲清，用户也不会长期依赖完整提示。认知迁移与习惯形成能力使产品借助已有经验降低起点成本，通过真实任务帮助用户建立规律，并逐步把控制权交还给用户。缺少这一能力，产品会在“新手看不懂”和“熟练用户被打断”之间反复摇摆，或把高频使用误当成真正掌握。

常见错误

把首次使用设计成必须完成的功能总览；

在用户尚无真实任务时集中讲解大量规则；

只追求第一次完成，不检查用户是否理解可迁移规律；

永久保留同等强度提示，使用户无法走向熟练；

为专家效率引入与基础规律冲突的特殊操作；

产品规则改变后沿用旧入口和旧反馈，放任负迁移；

用签到、连续天数、频次或不可中断记录制造使用依赖；

把停止使用视为失败，即使用户已经完成目标。

简洁案例

图片浏览中的双指缩放借用了“拉开即放大、合拢即缩小”的身体与空间经验。产品可在用户首次需要时提供轻量提示，之后让一致的手势和反馈支持熟练使用。关键不只是设计一个手势，而是判断既有经验能否自然迁入，并在实践中形成稳定规律。

与相邻能力边界

“用户心智模型理解能力”诊断用户当前带入了什么认知；本能力关注认知和行为如何在使用中改变、迁移并稳定。“认知负担控制能力”判断学习时一次承担多少内容；“用户行为动机与引导能力”判断用户为何开始和继续练习。具体教程文案、操作机制与反馈形式分别属于“语义与表达”“交互与反馈”和“感知体验设计”。

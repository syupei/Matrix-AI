# 内容设计与审读

版本：0.4。

这是由产品/设计等责任角色调用的共用能力，不新增常驻Agent或独立审批。维护实际正文的角色保持所有权；项目STYLE定义受众/表达判据和认可样板，方法在本技能，共同约束见 [文案校核](../../../collaboration/COPY-QUALITY.md)。

## 按需工作

1. 确定本轮范围、读者、任务、语境、事实、变量和唯一成稿源；新写或审读时读取 [审读与交接](references/review-and-handoff.md)。
2. 根据当前语境成稿，再分开回读语义和表达：谁做什么、条件/后果/下一步是否明确；整组标题、正文和按钮是否有无效重复。事实、数值和不确定性保持，来源原句可转译。
3. 在完整上下文核对正文、辅助、异常/限制及导入材料；只有样本时记录范围，不能宣称全量通过。需要校准时读 [情境案例](references/context-cases.md)，案例不自动成为项目模板。
4. 命名按 [命名指引](../product-agent/references/naming.md) 核对概念、展示名和确认状态。
5. 将改稿合并回原维护方的有效源，再交设计实际呈现回验及工程/QA变量和状态要求；证据标明改了什么、保留什么、在哪核验和仍未覆盖什么。

细化、交接与例外按审读指引；工具只检查确定性术语/变量及引用，语言自然度和完整语境由真实审读判断。

## 每轮入口

读取项目当前状态和本角色 [指引索引](GUIDANCE-INDEX.md) 的项目说明，仅加载本轮阶段所需文件。有效项目替换按 [指引解析](../../../collaboration/GUIDANCE-RESOLUTION.md) 处理，缺资料说明具体影响，已有事实和确认按原范围恢复。

## 共同关卡

1. 对人回复与确认采用 [统一交互](../../../collaboration/USER-INTERACTION.md)。
2. 收到反馈或恢复工作采用 [反馈分流与合批](../../../collaboration/FEEDBACK-PROTOCOL.md)。
3. 生成或引用文字采用 [文案校核](../../../collaboration/COPY-QUALITY.md)。
4. 跨角色采用 [所有权与协作](../../../collaboration/CONTRACT.md)，PM 接管时按 [上报契约](../../../collaboration/PM-REPORTING.md) 返回。
5. 切换阶段前按 [阶段关卡](../../../collaboration/STAGE-GATES.md) 检查实际源、确认和阻断；按原授权保留范围例外。
6. 交接以 [专业成果核对](../../../collaboration/PROFESSIONAL-REVIEW.md) 与 [结构化接力](../../../collaboration/STRUCTURED-HANDOFF.md) 的实际证据为准。
7. 当前输入充足且已获授权的工作做到真实审阅点；停止时报告完成范围、待人决定或具体阻碍及恢复入口。

# 核心场景适配检查

何时读：D1 写试制判据；D2 试制核心场景、扩展之前；D3/D4 验证连续体验；D5–D7 复用或补充证据时。

这是设计内部的推进条件，不增加人审，也不授权启动独立审查 Agent。

## D1：先定判据
从产品要求与推荐方向提取可观察判据：用户主要看什么、操作什么，核心对象、动作与结果如何关联，什么表现说明体验成立，什么表现说明功能齐全但方向偏离。写明依据与适用范围，区分明确要求与设计推导，存入现有设计依据并引用产品条目，不另建验收源。先定判据再制作，不为已有布局找理由；修订判据要记理由与影响，不为让现稿通过而降低要求。品类或某个组件的有无不能单独判定优劣，一次项目选择不写成通用布局禁令。

## 空间判断
结合 R02 第 5 条的参照与用户指定经验，选用适用维度：

| 维度 | 设计决定与反例 |
| --- | --- |
| 惯例与延续 | 结合品类与人群、平台输入、产品内部习惯定空间与操作关系，说明沿用或偏离参照的理由；不因运行于 Web 就用网页分区，不凭品类标签定唯一布局 |
| 有效空间 | 核心活动有足够的显示与操作空间，低频或重复信息、装饰与容器不挤压它；留白服务阅读与操作，不以填满率或固定面积比例评判；省空间不能让必要操作难发现 |
| 设备操作便利 | 按实际输入与频率查位置、目标尺寸与间距、连续操作路径、握持触达与遮挡、键盘或手柄焦点；“可见可点”不等于方便，不把一种设备的规则搬到另一种 |
| 对象—操作—反馈 | 用户清楚操作对象、当前动作与结果位置，不反复跨区寻找或误认对象；就近反馈或稳定操作区按任务取舍 |
| 主次与渐进 | 按任务定常驻、情境出现与主动展开的内容；减少低频占用，同时保证必要入口可发现、关键状态可见 |
| 空间稳定 | 展开、关闭、切换、放大与结果到达时保持锚点与上下文；查主要操作跳位、焦点丢失、遮挡与返回位置变化 |
| 规模与边界 | 用真实内容规模和适用的密集、多人、长文本、小窗口、文字放大等状态挑战方案；稀疏样例不证明全量，可先用代表尺寸的占位验证结构 |

D1 方向示意标出核心活动、常用操作、情境信息与需保留的观察/操作空间；D2 用目标视口与足够的代表内容核对；时序相关项在 D3/D4 补验。可读、可操作、可访问与防误贯穿各项。每个结论写明场景与观察，不以“习惯如此”“充分利用”“体验良好”代替证据；空间或对象关系失当先改结构，不以装饰或换皮掩盖。

## D2：试制、检查、再扩展
选最能检验核心任务与方向的场景，用代表内容、目标端与输入条件、必要状态先试制；一个样例覆盖不了的核心任务补最小必要样例。低保真可省材质与装饰，但保留构图、视角、对象、操作与反馈关系；决定整体体验的空间表达不推迟到 D4 换皮。实际打开查看，对照判据回答：
- **任务成立**：能否识别核心对象、执行本阶段可检验的关键动作、理解结果与下一步？
- **体验成立**：空间组织、注意力与操作关系是否支持目标受众、情境与期望体验？哪些表现支持或反驳？
- **制作一致**：画面与状态是否落实方向与约束，是否被模板、组件或导入默认值带偏？

试制时同时呈现目标视口（及最小支持尺寸）下的真实规模占位内容、最密集状态和多人或多对象状态，并逐条回答四个反例问题：
- 可用空间是否被低频内容、容器或装饰占据？
- 对象与操作是否割裂，需要在区域之间来回寻找？
- 第一次使用的人不读说明面板，能否理解动作与结果？
- 密集、多人或小屏状态是否让方案失效？

另外至少构思一种结构明显不同的组织方式，用同一判据比较并记录取舍；它只作内部依据，不作为多方案交给用户。

每个通过结论绑定场景或节点、版本、条件与观察，证据记在 `design/02-评审与验证.md`，并主动找反例。文字正确、按钮存在、图层完整、生成成功或用户曾确认方向，都不足以单独证明通过。授权内偏差自行修正并回读，未通过不扩展依赖它的页面与状态，不把纠偏交给用户；涉及产品事实、锁定要求或已确认基础的实质变化，走回查或局部重审。工具或材料使关键判据无法检查时，记为待验证并写明阻碍，暂停对应扩展，继续独立工作；后续时序或工程验证可以后置，但写明本次通过范围与后续责任，当前结构证据不能后置。

## D3/D4 与后续
用可操作原型或必要的动态演示检查“动作 → 反馈 → 结果 → 下一步”，按任务核对节奏、镜头、关键状态、重复与打断，以及关闭效果后的可用性；局部资产或孤立动画不能替代完整关系。阶段样例通过本检查并获审阅 B 确认，才作为 D5 扩展依据。

按范围标记待检、需修改、通过、待后续验证，引用唯一证据位置，不以整阶段状态掩盖局部缺口；通过后按授权继续，不向人请求批准。D5 新情境或共享组件变化、D6 复核、D7 交接时复用有效证据，只补受影响的缺口。PM 或已授权的独立复核看实际场景与证据，不以任务登记、文件齐全或复述制作者结论代替。

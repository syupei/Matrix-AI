# 素材元素：分级、制作与复验

何时读：D2 定占位；D4 素材元素阶段；D5 补齐素材；D6 复验；替换或新增素材时。制作工具与来源按 R09。

结构先于素材：D1 只定方向与参考，D2 用灰模确认空间、排布与样式结构，素材在审阅 A 之后、精细稿之前的 D4 集中设计。这样素材细节不干扰结构，风格偏差又能在精细稿之前暴露。

## D2 的占位
占位按真实尺寸、比例、层级与形态表达（如棋子大小、角色区域、图片裁切比例、按钮尺寸），标明将来的素材类别；影响入口识别的图标含义此时就定。不做材质、插画与最终配色。

## D4 的步骤
1. **列清单、分级、写简报**：从已确认的结构与 D3 状态清单列出需要独立设计的元素，按下表分级，每个素材家族写一份简报。
2. **风格锚点先行**：先做 3–5 个最能代表整体风格的元素——通常是主操作控件及其关键状态、当前状态提示（如回合、选中）、一个核心物件或主视觉、几枚图标。把它们**放进灰模的核心场景里**整体查看，作为 D4 第一个确认点：风格、控件语言与产品预期是否一致。不符就在这里调整，必要时局部回查结构。
3. **逐步制作与确认**：其余素材按家族对照锚点制作。需要独立设计的关键素材（标志、角色、棋盘或地图、主要物件）逐项或按家族确认；功能类与批量类对照锚点自检，以样张墙集中展示。确认默认按家族合批，用户要求逐项时逐项，不为每枚图标单独打扰。
4. **填充成代表稿**：把已确认的素材填入核心页面，连同关键交互在审阅 B 展示。D5 再按锚点补齐全部范围。
5. **结构回查**：素材暴露出结构问题时（例如物件需要更大的展示区），只回查受影响的结构并局部重审，不推倒重来。

| 类别 | 例子 | 何时定 |
| --- | --- | --- |
| 核心识别与体验类 | 主控件与 HUD、棋盘、角色、地图、主视觉、品牌标志 | D2 真实尺寸占位 → D4 锚点或逐项确认 → D5 补齐状态 |
| 功能类 | 操作图标、状态标识、空状态插图 | D2 定含义 → D4 定规范与代表集 → D5 补齐 |
| 批量内容类 | 大量商品图、关卡图、文章配图 | 前期只定规格与样本，按 [内容分期](../../../../collaboration/CONTENT-READINESS.md) 上线前补齐 |
| 多媒体 | 音效、音乐、动画、视频、语音 | D1 定是否需要与取向 → D3 事件映射或分镜 → D4 可播放样本 → D5 制作；核心体验依赖的（如掷骰、落子）按第一类 |

多媒体要有产品要求或核心体验依赖，不默认添加装饰性媒体（R06）。

## 简报与登记
- **简报**：作用与使用位置、状态、风格依据（引用锚点）、尺寸比例与裁切、安全区与文字区、格式与体积上限、可访问文本（替代文字、字幕、文字稿）、来源与权利、验收判据。
- **登记**（AS 编号）：家族、来源或生成方式、源与导出及版本、状态（占位/候选/采用/已替代）、使用位置、限制、确认依据。替换时检查全部使用位置。
- 先锚点后批量；生成类有界迭代，几轮无改进就换方法或报告缺口。多媒体按"分镜或关键帧 → 粗样 → 成品"推进，每一步放回场景看。成套导出各状态与尺寸，保留可编辑源。

## 三层复验
1. **素材本身**：符合简报；最小尺寸可辨认；格式、体积、透明边缘、图内文字正确。
2. **放回场景**：与控件语言一致；不压住文字与操作；各状态、各视口与裁切成立；静音、减少动态时有替代。
3. **整体一致**：同一家族全部排在样张墙上对照；占位残留清单为零或逐项列明；来源、权利与可访问文本齐全；体积在预算内。

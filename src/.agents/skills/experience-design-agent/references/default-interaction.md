# 默认动态与多感官交互

何时读：D1 定动态、声音、触觉设置；D3 扫描反馈机会；D4–D7 制作、扩展、验证与交接；产品要求视频、语音等媒体时。

没有另行指定时采用本基线：及时、连续、克制、一致、可打断、可访问。先复用有效的项目规范与平台原生组件；下列模式与参数是适用时的起点，不是统一外观；表现与场景控件协调（R05）。

## 有效设置
- D1 从用户指令、上游交接与指引索引的项目说明继承范围并记录来源。不要动画：停用所指范围的运动与渐变，以即时状态保留信息，不偷偷用声音或震动补偿；不要任何特效：停用额外的多感官效果。只禁动画不关闭已明确要求的声音；真实冲突局部回查。用户指定其他风格就替换对应默认。
- 遵守减少动态、静音、音量、触觉开关与设备能力：减少动态时去掉空间运动、弹跳、缩放与装饰循环，改为即时替换，必要进度保留静态文字或数值；关闭效果不等于没有反馈。媒体播放、告警等产品核心声音按产品行为与平台规则另行设计。

## 发现与选择
D3 沿任务、页面与共享组件逐一查用户输入和系统事件：按下/释放、选中/切换、展开/关闭、进入/返回、拖动/落位、等待/完成、失败/恢复、后台结果/内容更新。只覆盖存在的行为，不按数量硬造，也不等用户说“这里加动画”；D5 增量扫描新实例，D6 查遗漏。

先保证真实状态与可操作性，再定目的（即时确认、空间连续、离屏提醒），检查频率、风险与输入能力，复用组件，加入有收益的通道并删掉重复与干扰。无证据的频率标为假设；触觉只作输出，不为“质感”增加传感器权限。

每个事件族在交互规格记录一次：源条目/对象 → 触发与业务成立时点 → 用户此刻需要知道什么 → 模式与理由 → 视觉/触觉/声音 → 组件与例外 → 制作状态 → 验证状态；不采用的也写理由。整页没有新增动画可以成立，但要说明反馈怎样覆盖。

## 默认模式与起始参数
数值是本包的设计起点：原生或项目参数优先，正常速度观察后调校并登记最终值；不要求每种控件都缩放。自定义进入曲线从 `cubic-bezier(0.2, 0, 0, 1)`、退出从 `cubic-bezier(0.4, 0, 1, 1)` 起步，非 Web 工具用等效缓出/缓入并记差异。时长不作为接口完成的计时器。

| 模式与触发 | 视觉起点 | 触觉/声音 |
| --- | --- | --- |
| 按压：有效按下/释放 | 按下即可辨，色/明度约 80ms，释放约 120ms，取消即恢复；焦点清楚 | 复用原生，不额外震动或发声 |
| 选择与离散刻度：值真正变化 | 标记即时体现，局部过渡约 140ms，不延迟真实状态 | 触控离散选择有收益时用系统选择触觉；默认无声，键盘移动不发声 |
| 菜单/浮层：打开/关闭 | 自触发位置短移约 4–8 逻辑单位并淡入，进入约 180ms、退出约 140ms；焦点与退出规则明确 | 默认无 |
| 展开/导航/列表重排：结构改变 | 保持对象、来源与去向关系，约 200ms；高密度高频更新可即时替换，保持焦点与可见位置 | 仅视觉，新增条目不逐条提示音 |
| 拖动/吸附/边界：移动与释放 | 拖动直接跟随；释放从当前位置收敛，约 220ms 缓出；需弹性时用平台弹簧并登记实际参数与收敛时长，不跨库照搬 | 有意义的落位或阈值可短触觉，带回差与去重，不逐帧触发；默认无声 |
| 接收/等待/结果：请求状态改变 | 立即显示接收或执行中，真实结果到达才显示完成；状态替换约 160ms，快速完成不强等动画 | 重要结果且有收益时用系统成功/失败触觉；离屏提醒或产品要求时才用短声 |
| 错误/风险：校验或操作失败 | 靠近问题显示文字或标记及下一步，约 140ms 或即时；不以震动或抖动表达错误，不逐键打断 | 重要离散失败可用语义触觉；默认无声 |
| 罕见重要完成：真实里程碑 | 简短可跳过，约 300–450ms 起，不锁下一步；严肃或高频任务用普通结果模式 | 按价值选一次短触觉或短声，不必三通道齐开 |

“逻辑单位”映射到目标端的 pt、dp 或 CSS px 并按实际尺寸检查，目标端不支持时不称精确复现。组件已有原生触觉或声音时不叠加；多通道对齐真实事件，已取消或过期的事件不迟到播放。普通按钮、导航与刷新默认静音；短声音写明素材、音量策略、去重与停止条件。

## 规格与各阶段
同一交互条目补齐：起止状态、属性与方向、时长/曲线或弹簧参数、业务提交时点、重复/打断/退出、减少动态替代、通道开关与不支持时回退、组件或原型节点、采用版本。例：保存按下即进入按压态，释放后提交并显示处理中，服务确认成功才显示“已保存”；进行中的过渡可被最新状态接续，不等过渡结束才提交。去重与撤销是否成立按产品基线，不由动画决定。

D1 在设计基础中定表达取向；D2 只表达影响结构的进入、返回与展开；D4 的可操作或可播放样例随审阅 B 呈现，标明声音/触觉的模拟与设备限制；D6 按 R07 走查；D7 交接模式与参数、使用位置、可编辑源、播放入口、观察与剩余责任。不为单个动效增设审批。有匹配的交互 skill 时按 R09 采用，没有也执行本扫描。只能做静态状态的工具不能证明动效，无法播放的部分写明规格、阻碍与下游验证任务。声音素材存在不等于播放通过，触觉规格不等于真机验证；设计阶段能验证的当轮验证，设备、系统设置、性能与真实业务时序由实现与 QA 接续，写明条件与判据。

## 视频、语音等媒体
需要产品要求或相应授权；装饰性媒体不自动成为需求。启用时在交互/状态规格写明：表达的事实（意图、已接受、最终结果或持续状态）、接收者与产品依据；通道与优先级（数值有依据或标为建议）；触发、停止与重复时重播还是合并；取消、暂停、离开或权限变化时继续、重播还是不补播，避免过期的成功提示；静音、减少动态或通道不可用时保留必要信息；素材来源、版本、使用位置与演示限制。产品维护事实与业务成立条件，设计维护呈现；不能把点击意图表现为业务成功，未制作的资源标为占位。D6 查通道关闭、中断与状态结束。

# 专业 Agent 技能包

本包提供产品、设计、工程承接、项目管理和专业协作五个角色，以及共用内容审读能力。安装只提供配置与工具，实际实例和通道由使用方宿主决定。

## 安装与升级

需要Python 3.10+。先预检，再应用：

```sh
python3 install.py --target /你的项目
python3 install.py --target /你的项目 --apply
```

安装按内容差异执行，覆盖前备份，保持业务成果、确认和未知定制。发生定制冲突先合并；自定义指引索引保留并报告待核对。回执与备份在目标management目录；按项目保留策略处理，不自动删除。旧版重复能力标准可在确认所有自定义引用迁移后自行归档，升级器保留旧文件以免破坏定制引用。

## 使用

读取项目AGENTS.md，按任务选择岗位SKILL.md；每轮只读对应阶段与项目说明。共享标准在shared/standards，按能力索引定位；完整来源在shared/sources。单独迁移一个skill仍需携带共同规则与共享文件。

确认和步数采用 [用户交互](collaboration/USER-INTERACTION.md)，可使用宿主控件、[通用审阅页面](shared/review.html)或文本；切换阶段运行 [阶段关卡](collaboration/STAGE-GATES.md)。控件展示、回传收到、专业检查、用户批准分别记录。

角色从已有有效阶段恢复，不重新批准无变化的内容。技能版本、发布范围及文件摘要见MANIFEST.json。未实现的E2/E3和真实运行通道不因安装而出现；程序检查不代替专业判断或用户测试。

# 执行实例与辅助成员

先读本次任务包与已登记任职，核对任务/父任务 ID、负责人、本人实例、版本、许可写范围及回交通道。只处理该范围，按所需阶段读取专业指引和上游依据；不因加载整套 skill 重启全项目访谈或要求全套阶段审批。

实例工作区保存候选成果和事实检查点，共享产品/设计/工程正文及总状态由指定维护者整合。引用同一有效基线，不私自复制成另一套正式源。工具只在本任务有效授权集合内选择；指定工具不可用时按 [工具授权](TOOL-ACCESS.md) 回报，不能借全局可见工具绕过分配。

执行者可以分析内部步骤；需要继续调配实例时须有明确负责人任职和团队额度，不从收到一个任务推导无限转委派权。范围内自行修正并自检；跨任务业务矛盾、未知来源事实、资源不足交负责人，避免分别向真人重复提问。负责人能解决的问题不推给真人；必要的人答复经统一入口记录后接续。

返回任务 ID、输入与产物版本、实际产物位置/摘要、逐项证据、自检、偏差及未决，说明是否停止写入。自检不是独立验收，收到回应不是成果已采用。过期、已弃用或被重派的结果保留供核对，不覆盖当前源；缺工具或通道如实报告，不伪造送达或运行。

前台只登记、路由和展示，不作专业取舍；通信成员只负责真实传递与接续，不因辅助任职拥有其它专业源的写权。

# 实例工具授权与隔离

何时读：配置实例工具、派生执行者、调用外部工具、受阻换工具、处理撤权或共享会话时。

工具偏好说明优先用什么；工具授权限定能用什么。有效能力是用户/项目授权、成员委托、任务范围与实际连接权限的交集。工具可见、skill 已加载、目录独立均不证明已获权限或调用成功。

每次执行绑定真实实例、任务、运行、输入基线和授权修订；授权包含工具连接、操作、明确资源 ID、有效期/结束条件、调用配额和可选替代工具。负责人只能分配已有委托内的能力。凭证由宿主保管，不放共享文件或提示词；请求和结果只携带稳定引用。

只在本任务的授权集合中发现和选择工具。受阻时可以切换已有授权且适用的替代项；其余保留具体阻碍并交负责人协调。新费用、资料外发和权限扩张按真实授权处理，不能因工具失效默认采用另一个服务。

## 强制检查与宿主边界

[tool_gateway.py](tools/tool_gateway.py) 是宿主侧实际调用库：Gateway(database, grants, adapters, live_check)。只有 call 接口交给工作实例；配置、open_run、撤权、settle 及数据库留在可信宿主侧。令牌只通过该实例的运行通道交付，绑定身份，不接受模型改写 instance_id。

每条 grant 含 instance、tasks、connection、operations、resources、expires_at（时间戳）、max_calls、revision。open_run 绑定任务/运行/基线和 grant IDs；live_check 必须按当前任务、任职、输入版本、暂停/撤回情况返回实际有效性。不存在、失效、超范围或未接入的能力拒绝执行，不自动寻找别的连接。

适配器必须实现 validate(operation, resource, parameters)、lock_key(resource)、invoke(operation, resource, parameters)。只由可信宿主注册，固定实际连接及凭证，严格限制参数，拒绝任意脚本、任意目标 URL 或隐藏资源替换入口。适配器若不能可靠限制粒度，不能宣称节点级隔离，改用独立文件/账号或受控串行。

网关在副作用前检查身份、操作、资源、配额和会话占用；同一 call_id 的成功结果复用，冲突请求被拒。失败或中断保留 executing/uncertain 占用，不超时重发。宿主核对远端真实结果后用 settle 记录证据；撤权只阻止后续调用，已发出的操作需核对，不声称自动回滚。

FileArtifactAdapter 是仅支持指定资源读写的参考适配器，用于宿主保护的候选文件。它不等于外部设计服务适配已接入；每个外部服务都要验证连接、资源粒度、会话状态与拒绝行为。不同适配器共享同一实际会话时必须返回相同 lock_key。

**强制隔离的前提**：工作实例不能直接读取网关数据库/凭证、修改宿主代码或授权、绕过网关访问受保护服务。若通用终端、网络或浏览器仍可直达，只能标为“指令约束”，不能称强隔离。不得通过把配置放同一用户可写目录就宣称安全边界。宿主无法提供该条件时，使用已有受限工作器或独占会话，并说明限制。

## 设计及其它并行工具

多实例可以分别使用不同工具或同工具的不同文件，但共享活动文档/桌面焦点/登录会话可能串写。优先独立会话和候选文件；不能隔离的实际会话作为独占资源串行执行。共享组件库默认只读，由指定维护方整合。

交付同时核对可编辑源、格式、基线一致性和来源；截图、工具调用成功不等于设计成立。先证明获准操作成功、越工具/连接/文件/操作被拒，再声明相应隔离范围；另测撤权、旧运行和重复调用。当前接入档位明确写“已验证隔离 / 受控串行 / 仅指令约束 / 未接入”，不推断宿主或模型名称意味着隔离能力。

运行凭证绑定授权完整摘要及修订；授权内容或修订改变后，旧运行凭证失效，由宿主复核后建立新运行。

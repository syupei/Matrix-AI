# 项目专业协作运行入口 0.1

这是 professional-collaboration/0.1 的运行扩展，补实际实例路由、唤醒、请求账本和统一人工入口，不替代原 [专业协作约定](CONTRACT.md)。专业工作及确认仍按各自 skill 和用户授权执行。

发生具体跨角色澄清、收到协调请求、恢复待决问题时，读取 [professional-agent-collaboration](../.agents/skills/professional-agent-collaboration/SKILL.md)。在已有协作授权中，明确要求使用真实可用的独立专业子Agent/任务通道完成问询和接续；普通来回不需要用户手工搬运。

主任务是唯一人类对话入口。责任角色可自行解释或在委托内决定则直接处理；确需人时提交具体问题，由主任务展示并登记真实答复，再唤起原角色继续。缺工具、未知专业事实、待批准的业务变更必须区分；不得把每个工程选择都交给人。

角色与在途请求的实际运行状态位于 `collaboration/runtime/state.sqlite3`，用脚本 `status` 查看；未初始化意味着运行接入未完成。原 `角色执行配置.md` 等专业资料继续保留，实际实例/唤醒以当前账本为准，旧配置中“未启用协作”的历史事实不应阻止后来明确获授权的接入。

不改变产品、设计或研发既有成果、确认或阶段。安装机制不批准当前候选，不创建后续架构/编码工作，不安装持续监测。实际宿主无法唤醒时据实报告，不以文件存在冒充运行成功。

# professional-agents-kit v0.19

交互与视觉设计的流程调整：先用灰模确定结构，再集中设计素材元素，并让风格偏差在精细稿之前暴露。其他角色的职责与流程不变。

## 主要变化

- **灰模先行**：D2 只做灰模，占位按真实尺寸、比例与形态表达将来的素材，不做材质、插画与最终配色，结构设计不受素材细节干扰。
- **审阅 A 加入核心交互**：除页面分布、粗骨架与流转外，同时展示核心活动的交互示意（可点击或关键帧），让交互形态与结构一起确认。
- **素材元素阶段（D4）**：在精细稿之前列出素材清单并写简报，先做 3–5 个风格锚点放进灰模的核心场景请人确认，再按类别制作；关键素材逐项或按类别确认，然后填入核心页面形成代表稿，在审阅 B 展示。新增素材指引，包括分级、来源顺序、多媒体推进步骤，以及素材本身、放回场景、整体一致的三层复验。
- **换视角复核**：D2 核心场景检查通过前、审阅 B 提交前，各做一次只读复核。复核者只看产品输入、判据、截图与原型，任务是找反例；宿主不支持或项目停用时如实说明。
- 产品侧在 S1、S5 登记已有素材、品牌资产及其使用权利。
- 安装器可识别 v0.18 的未改动文件，已安装 v0.18 或 v0.17 的项目可以直接升级。

## 版本

产品 0.23、交互与视觉设计 0.19；研发承接 0.8、项目管理 0.8、专业协作 0.9、内容设计与审读 0.5、产品能力模型 1.0 不变。

## 检查与行为评测

- 维护测试 136 + 23 + 14 项通过；从 v0.18 与 v0.17 升级的端到端检查均通过（12 项）。
- 行为评测：在原有 5 个情境之外新增 2 个设计情境：进入 D2 时审阅 A 是否包含核心交互；D4 是否先做风格锚点、再分批确认素材。v0.18 与 v0.19 各运行一次，共 16 轮。25 项判据中，v0.19 全部通过；v0.18 未通过 3 项，均为本版新增的行为：审阅 A 的核心交互演示、先做风格锚点、分批确认素材。原有 5 个情境两版都通过，v0.19 没有退步。
- 观察：在 D1 基础稿缺失的情境中，v0.18 直接做出基础稿请用户确认，v0.19 先请用户选择"提供原稿"或"重做"，多一轮往返。两版都没有越过 D1。这个差异与本版改动无关，只记录，不计分。
- 评测方式的限制：
  - 本次在另一个 Agent 会话中进行，无法启动独立的命令行进程。每一轮改由全新上下文的子 Agent 在隔离的临时项目中执行，回复由维护会话原样记录。
  - 评分由执行本次修改的会话完成，未经人工复核，存在自评偏差。
  - 每个情境只运行一次，是初步的回归探针。
  - 两个新设计情境没有前序成果（产品基线、灰模、D3 规格），两版都停在补充资料处。因此只比较了它们说明的做法与顺序，没有实际产出灰模、核心交互演示或风格锚点。
  - 文字情境不证明视觉质量、素材质量、空间布局或设备体验。

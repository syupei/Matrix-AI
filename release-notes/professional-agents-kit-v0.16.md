# professional-agents-kit v0.16

专业技能改为唯一可编辑src源码、精简入口、共享能力标准及可核验的构建发布流程。

- 六项SKILL入口均少于2500字符，专业细节按阶段读取；产品入口由6563字符降至2436字符。
- 公共确认规则集中维护，提供Codex/Claude宿主适配表、通用离线审阅HTML和文本回退；真实答复绑定成果版本及范围。
- 新增只读阶段关卡检查，核对顺序、文件摘要、确认范围、实际展示与回应记录。它不认证身份或代替专业判断。
- 产品与设计共享一份能力标准和原始材料。使用方ZIP排除维护测试、评测、业务项目资料、个人状态及备份，运行内容从约5.25MB降到2.82MB。
- 构建从src生成；新版本通过Git标签与发布清单保存，不再新增完整源码目录。正式发布要求真实行为比较证据与前版无退步，证据缺失、变更或失败会阻断。

验证包括163项机制测试、6项技能格式验证、509条本地链接核对、隔离升级与重跑保护、真实浏览器离线审阅交互检查。五个合成场景与v0.15进行了实际模型配对比较：留言板两轮澄清、反馈合批、D1未确认、真实账号集合与命名、结果未知文案；17项判据两版均通过，共12个验收运行回合。属于初始回归探针，没有宣称全部规则或视觉能力达标。

边界：文字场景不证明视觉质量、空间利用率、设备体验或所有宿主行为；Claude原生控件未实跑。旧版公开历史保持不变。既有项目定制文件和旧孤立文件按保护策略保留；发布不会自动安装到业务项目。

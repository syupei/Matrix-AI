# professional-agents-kit v0.18

合并 v0.17 与 v0.16 两条精简线的优势部分。以 v0.17 的内容为基础，并入 v0.16 的阶段检查、离线审阅与发布前行为评测。六个角色的职责、阶段和人审节点不变。

## 主要变化

- **阶段切换检查**：新增 `collaboration/STAGE-GATES.md` 与 `collaboration/tools/stage_gate.py`。产品、设计、研发承接在切换阶段前运行只读检查，核对阶段顺序、成果摘要、确认范围、实际展示与用户回应的记录，把"未确认不越过审阅节点""批准绑定版本与范围"落成可检查的机制。新增 `--digest` 辅助命令，用于计算成果摘要。
- **离线审阅页**：`collaboration/tools/review.html` 可导入审阅请求、导出回复文件，适用于对话之外的审阅；页面不联网，也不会自动批准。
- **保留 v0.17 的全部改进**：共同底线 `CORE.md`、按需加载、按二级能力读取的能力标准、不绑定宿主的写法、安装器的宿主约定与退役文件处理、设计核心场景的压力状态与反例检查。
- **升级**：从 v0.17 或 v0.16 升级时，本版不再使用且未被改动的文件先备份再移除（包括 v0.16 的 `shared/` 目录）；项目改过的文件保留并报告。
- **维护流程**（不在使用方包内）：发布仓库的 `src/` 作为唯一源码；构建时检查宿主名、历史说明、隐私、链接和入口长度（SKILL.md 不超过 3,500 字）；发布前要求与上一版做行为对比且不退步。评测运行器支持 Codex 与 Claude Code 两种宿主。

- 维护测试 136 + 23 + 14 项通过；从 v0.17 与 v0.16 升级的端到端检查均通过；新装项目中的阶段检查脚本可直接运行。
- 行为评测：沿用 v0.16 的 5 个情境（留言板两轮澄清、反馈合批、D1 未确认、账号集合与命名、结果未知的提示文案），v0.17 与 v0.18 各运行一次（共 12 轮），17 项判据两版全部通过，v0.18 没有退步。设计 D1 情境中，v0.18 按新增的阶段关卡规则生成了审阅请求记录。

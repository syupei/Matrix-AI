# professional-agents-kit v0.17

一次整体精简与通用化。六个角色的职责、阶段、人审节点和已确认的做法不变。

本版在 v0.15 的基础上完成，与同日发布的 v0.16 是两条独立的精简线：v0.16 的行为对比评测、阶段检查脚本和 `src/` 构建流程不在本版中，将在下一版比较后合并。从 v0.16 升级时，安装器会移除 v0.16 独有且未被改动过的文件（如 `shared/` 与阶段关卡说明），项目改过的文件保留并报告。

## 主要变化

- **按需加载**：新增所有角色启动时读取的共同底线 `collaboration/CORE.md`；各 skill 只保留核心流程与关卡，其余指引按索引中的"何时读"加载。产品接到新需求的首轮必读由约 5.9 万字降到约 1.6 万字，设计进入 D1 由约 5.8 万字降到约 2.3 万字；每次会话常驻的入口块约 1 千字。
- **能力标准独立为共享 skill**：七大能力原文拆为按二级能力读取的 `product-capability-model`，查一项能力由读整个模块（最大约 6.8 万字）降到读单个文件（最大约 3.3 千字）。发布包由 5.2MB 降到 1.3MB。
- **不绑定宿主或模型**：规则中不再出现特定宿主的工具名；确认选项、子 Agent、消息工具改为能力描述，项目在 `collaboration/runtime/host.md` 登记实际使用的工具。安装器新增 `--skills-dir` 与 `--entry`，可安装到不同宿主约定的 skill 目录和说明文件。
- **可公开下载**：去掉测试项目名、制作过程与版本沿革、决定编号、本机路径和真实品牌示例。
- **升级更干净**：安装器迁移旧的入口块；本版不再使用且未被改动的文件先备份再移除；项目改过的指引索引保留并报告。
- **规则落实为可检查的做法**：设计核心场景检查加入真实规模与密集状态、四个反例问题和内部对照构图；写明提前单独审阅属于审阅 B；写明 PM 任务进度与流程步数的关系；写明协作账本由谁初始化；行为观察清单改为可以实际执行的检查方法。

## 版本

产品 0.21、交互与视觉设计 0.17、研发承接 0.7、项目管理 0.7、专业协作 0.8、内容设计与审读 0.4；新增产品能力模型 1.0。

## 检查与限制

- 包内测试 92 项、协作运行脚本测试 44 项通过；从 v0.15 与 v0.16 升级的端到端检查均通过（项目索引保留、业务文件不变、退役文件先备份再移除、重复运行零改动）。
- 尚未在真实项目中做多轮行为试验；不绑定宿主的写法只在一种宿主上有运行记录。格式与脚本测试不代表 Agent 的实际判断、设计与文案质量。
- 安装不会启动任何 Agent，也不批准任何业务成果。

# Matrix-AI 0.36

- 安装入口标题与包版本在构建时核对。
- 产品计费规则采用带校验器的结构化格式，覆盖价格、扣费、退款与续费。单对话交付逐项标注专业。产品草稿和反馈登记新增文件回读核对。
- PM 通知预排根据行动人和任务数据生成。任务工具比较实现者和检验者的模型配置，实际检验以运行记录为准。
- 技术评审列出运行证据层级、可复现的试用步骤、预期及限制。骨架验收明确项目阶段依据、日志隐私、故障注入及告警收件验证。安全检查表和缺专家时的三种处置分别引用各自的规则。

## 验证与限制

- 613 项程序检查、63 项隔离安装检查通过。独立的本地回环样例实际收到与故障请求对应的告警回执。
- 本版按用户授权豁免全量比较。发布验证只涵盖产品草稿、批次反馈、安全检查、工程骨架及技术试用证据五个情境。两侧以 0.35 为基线，按各次修改后的实际源码留存证据。
- 安全措辞修订后，Codex 单轮 4/4，Claude Desktop 三轮均 4/4。骨架修订后 Claude Desktop 三轮均 5/5；Codex 两版各新跑三轮，按确认通过次数保守比较，日志隐私及告警验收均无退步。日志隐私的候选确认通过率为 1/3，评分分歧保留。
- 产品草稿情境中，两份已写入的附带规格缺少回读回执。其余 120 个情境不计入定向发布验证，Codex 在早期候选上完成的 64 个额外运行仅供参考。
- 0.36 不作为下一版行为对比基线。0.37 继续以 0.35 为基线。 [豁免记录](../release-waivers/matrix-ai-v0.36.json)

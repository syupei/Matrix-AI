# Matrix-AI 0.38

## 功能与使用变化

- 更明确地处理"直接开发""直接上线""别问了直接做"等推进要求：在已有授权范围内继续工作，不把推进理解为省略必要环节，也不重复询问已确认且未变化的事项。需要省略具体事项时，仍由有权决定的人明确接受相应风险。
- 把别人的回复当作批准依据，或请人作决定之前，先核对消息的实际来源，以及对方对这件事有没有决定权。无权的意见连同现有材料转交负责决定的人，不改记在别人名下。已有的有效确认直接引用，只补核缺少的部分；计划里已经授权的动作，按已有确认继续推进。
- 外部需求先作为输入，经专业分析和必要确认后再进入制作，不能直接当作已经完成的专业成果。
- 团队任务在执行人未定、所需材料还没准入时，可以先登记计划、依赖和缺口。派发和开工时再完整核对人员、独立检验和材料准入；先登记不代表这些已经通过。
- 改善专业之间的方向材料交接，以及返工、更换上游成果、缺少专业时的代做、规则维护和委托审阅的接续。
- 交付前逐份读取本轮成果，并按实际文件给出链接，减少说明与文件不一致的情况。
- 关键技术选择和影响成品的默认选择会说明对使用者的影响，并区分估计与实测。发布准备承接当前有效的质量验收；内容或上游工作变化后，不能继续把旧验收当作已经完成。是否发布仍由人决定。
- 缺少质量验收时，已经选定的处置方式会原样沿用，不再重复请人选择；未验收部分的风险是否接受、能否发布，仍由发布决定处理。
- 通知草案可以在批准发送之前先准备好，不必等到批准才开始。
- 自有专家与内置专家遵守相同的阶段、确认和交付要求。导入包上限提高至 1000 个文件、32 MiB。

## 使用时请注意

- 方向材料发生变化时，所有范围都需要重新审阅。
- 单对话中已确认的方向，暂时不能直接作为团队工作的依据。转为团队时，可沿用已有文件，由项目管理按团队流程重新检验、展示并请人确认一次，不需要重新访谈。
- 接管已有成果时，旧成果应作为输入登记并完成准入，不能补记成未按流程开展却已完成的生产任务。已经开工的生产工作仍须满足本版流程要求，不能仅凭旧的完成说明略过所需环节。
- 提出上线的人没有决定权时，会转交负责决定的人，但不一定会主动把不涉及上线的准备工作继续做完；需要时请明确提出。
- 导入外部专家的完整流程（作者交回与独立审阅）本版没有完成端到端验证；导入的文件数量与大小上限的改动已经生效。
- 工具只核对文件和记录，不能证明确认者的真实身份，也不能代替专业质量判断；关键决定和成果质量仍需要人把关。
- 截图和记录齐全不代表画面与实际体验合适，仍需要人查看画面并实际使用。
- 未列入确认记录的文件（例如图片、素材）在确认后仍可能被改动，确认不会锁定它们，使用时需要一并核对。

## 已知限制

以下情况在本版中仍可能出现，需要人工核对。

- **确认与阶段接续**：
  - 你在对话里已经确认、但项目文件还没有对应记录时，可能会再次索要记录；
  - 也可能不继续准备素材清单、风格样张和合并审阅的安排。
  - 遇到这种情况，请指明已确认的内容、适用范围和当前阶段；新产生的成果仍需按各自范围审阅。
- **多人通知与接续**：
  - 给多人的通知可能漏掉查看入口、回复方式或能否等待。请检查每位需要行动的人是否收到一条完整消息：要做什么、看哪里、怎样回复、卡住了谁、能否等待。
  - 协作返回时，请核对哪些事项已实际送达、哪些仍需接续。对能否唤醒其他会话或子任务的说明可能不准确，不要据此假定已经通知或会自动恢复。
- **专业边界与交接**：
  - 讨论结论可能没有交给产品角色写进正式文件；
  - 情境说明可能混入未经内容或工程专业确认的最终文案与内部处理方式；
  - 依赖上游、待确认条目的开工条件可能解释不全。
  - 涉及儿童个人信息、付费或税务时，请确认已经指出缺少的专业、所需资质和风险，并交给合适的专业人员处理；规则交给研发之前，还要核对由谁完成必要的检验。
- **设计与实现的核验**：
  - 可能漏掉逐项的外观差异、问题归属或阻断范围；
  - 素材齐全、功能可用，不能代替外观还原的核对；
  - 方向稿也需要展示并取得相应确认。
  - 请逐项核对差异，明确哪些要修、由谁修、哪些部分可以继续，修正后再复查。
- **验证与发布前置**：
  - 试用和恢复目标的说明，可能没有列全尚未验证的真实环境、负责人或发布前的恢复演练；
  - 外部需求文档可能被过早当作已经确认。
  - 直接进入开发时，请复用已有的有效成果，核实真正缺少的工程承接与技术方案，并保留后续的测试、验收和发布决定。
- **共用环境与破坏性操作**：
  - 共用的编辑环境可能发生抢占或串写，请安排独占或依次操作；
  - 删除等破坏性脚本，请人工检查目标路径、路径边界和"只处理普通文件"等限制，先预览操作范围再执行。

- 美术专业与图像生成接口。

# Matrix-AI v0.33

本版把专家来源、专业、实例与模型分开绑定，并提供外层平台可调用的任务和运行接口。同一专业可以并用内置专家与导入专家，由各自模型执行；平台接管进程后，原本地调度器不会重复启动。用户已审阅本说明，并于2026-11-13明确批准按以下限定支持范围提交发布。

- **实例身份**：稳定 ID 绑定专业、专家包版本、模型及运行器，别名用于称呼与查询。改名保留历史映射，任务仍引用原 ID；档案和视图展示别名。旧实例按内置专家处理。
- **专家导入**：读取固定提交的 HTTPS Git 来源，保存原始文件、摘要、适配说明与薄入口。专业类别必须预先由人配置；不运行来源 hooks、安装脚本或插件。转换保留专业方法与决定边界，无法适配的依赖或冲突明确阻断。
- **准入与停用**：分别核验专业方法保留、实际写入隔离和交接契约。进程成功、文件存在或关键词出现不能代替准入；失败及停用版本保留，修正产生新版本。启用专家包、派生实例、启动进程与成果验收分别记录。
- **平台协议**：新增版本化 JSON 门面及请求 schema，复用现有任务数据库；提供能力查询、专家接入、任务查询/命令、只读计划、原子领取、运行回报/取消及白名单脚本请求。请求与事件去重，过期修订拒绝，调用身份由可信平台映射。
- **运行权与恢复**：local/external 模式有唯一控制器；领取时重新检查就绪、授权与版本。未知运行保持占用，取消请求不冒充实际停止，迟到或失效授权的成果不能覆盖当前状态。已配置控制器的项目不再用旧本地调度心跳推断平台运行情况。
- **受控交接**：执行者只写本实例 private/public 工作区，控制器校验交接文件及任务范围后登记，执行者不能直接修改任务库。候选经既有检验和适用确认后再采用到正式源。
- **宿主与接入文档**：提供本机参考工作器、两类隔离适配、易读平台 guide、字段契约与宿主附件。各宿主按实测版本登记，其他 shell 通过同一协议接入并自行验证其能力。

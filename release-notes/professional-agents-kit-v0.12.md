# 专业 Agent 完整包 v0.12

基于v0.11，保留已确认的产品情境与设计方向准则，落实四项经确认的改进：

1. 主要产品阶段完成后主动展示成果、询问调整或补充，得到明确回应再推进依赖阶段；仅明确授权Agent自行判断的范围免审。原设计三个审阅节点保持。
2. 必要事实、关键操作文案和代表内容提前；非阻断批量资料由PM在主要功能/设计稳定后、上线验收前组织补齐，产品审读，必要时设计及实际研发/QA复验。后置不等于免检或内容已齐。
3. 用户声明仍有待提交意见时先收集，合并重复、识别冲突，再按基础影响、当前阻断和依赖排序；收集期间继续独立工作，明确即时修改按指令处理。
4. 产品品类、核心体验、运行端与表达风格分别定义，通过现有协作机制交接/通知设计；设计返回采用版本、实际影响、成果证据及未决。空间与交互依据核心活动设计，避免默认通用网页模板；品类标签不直接决定布局或新增功能。
